# Page images

Final stimulus pages, in two resolutions:

- `page1-4_full.png`: full resolution, 1920 × 1080 px (the screen resolution), copied
  from `stimuli/tobii_images/`. Used by `derive_et_measures.R` and the report figures.
- `page1-4.png`: thumbnails, 256 × 144 px, copied from Tobii Pro Lab's thumbnail export
  (same Tobii file names; the export itself has been removed from the project). Kept for
  reference.

Both were matched to pages by comparing the text with the sentence AOIs in
